## Structure

- `index.html` — main website
- `contact.html` — professional contact page
- `privacy.html` — privacy policy
- `terms.html` — general terms of service
- `styles.css` — responsive visual system
- `favicon.svg` — Mitchell Stack identity mark
- `robots.txt` and `sitemap.xml` — search engine support

The site is static, responsive and deployed automatically through GitHub Pages.
